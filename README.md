# **Strings Of Yoga**

This project was generated with [Angular CLI](https://github.com/angular/angular-cli) version 16.1.0.

**Strings Of Yoga** is a portfolio website for a London-based yoga instructor.
The platform showcases courses, resources, and professional yoga offerings—built as a modern full-stack web application.

The project is currently in the **building/development phase**.

---

## 🌟 **Main Features**

* Yoga instructor portfolio
* Course listing & details
* Resource sharing functionality
* Clean and simple UI focused on usability
* Backend support for dynamic content (in progress)

---

## 🛠️ **Tech Stack**

* **Angular** (Frontend)
* **.NET** (Backend APIs)
* **MongoDB** (Database)
